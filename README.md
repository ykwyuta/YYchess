# うごきがみえるチェス

スマホで遊べる、**こまの動きを覚えていない子どもでも遊べる**チェスです。
姉妹作 [うごきがみえる将棋（YYshogi）](https://github.com/ykwyuta/YYshogi) と同じ作り・同じおたすけ機能で作っています。
駒をタッチすると動けるマスが光り、駒のまわりには動ける方向のマークが付いています。ルールを覚える前から一局指しながら覚えられます。

ブラウザだけで動く静的サイトです。ビルドもサーバーも要りません。Cloudflare（Workers の静的アセット配信）でそのまま公開できます。

- CPU 対戦（はじめて／よわい／ふつう／つよい、しろ・くろ・おまかせ）。「はじめて」はチェックのチャンスだけは逃しません（チェックメイトできればして、チェックできればチェックする）が、それ以外は半分以上の手を適当に指し、駒の取り合いも先読みしないので、駒の動きを覚えたばかりの子どもでも勝てます
- ふたりで対戦（1台のスマホを交互に使う）
- ハンデ（駒落ち）：ポーン 1つ〜クイーンとルーク 2つ
- **チェックメイト問題 50 問**（1かいでメイト 20・2かい 20・3かい 10）。全問に解説つき
- 対局は自動保存。ブラウザを閉じても続きから遊べます
- ホーム画面に追加するとアプリのように全画面で使えます

## 子ども向けのおたすけ機能

| 機能 | 内容 |
| --- | --- |
| うごきマーク | 盤上の駒のまわりに、動ける方向を表示。●＝1マス、▲＝どこまでも、○＝ナイトのジャンプ、×＝ポーンが取るときだけ進める方向。 |
| 動けるマスが光る | 自分の駒をタッチすると、行けるマスに緑の●、取れる相手の駒に赤い○（アンパッサンで取れるマスも赤い○）。キャスリングできるマスには ⇄。キングが取られる手は最初から選べません。 |
| あぶないマーク | 行き先が取られそうなマスには「!」。いま取られそうな自分の駒には赤い「!」が点滅。 |
| 相手の駒を見る | 相手の駒をタッチすると、その駒が行けるマス（ポーンは取れるななめ前も）がオレンジで表示されます。 |
| 駒の説明カード | タッチした駒の名前、5×5 の動きの図、やさしい説明。ポーンを選ぶと昇格できる段が紫に、キャスリング・アンパッサンができるときはその説明も出ます。 |
| 昇格（プロモーション） | 「なにに かわる？」で、クイーン・ルーク・ビショップ・ナイトを動きの図つきで選べます。 |
| チェックのお知らせ | チェックされると画面とキングのマスが赤くなり、「チェック！」と表示。 |
| ヒント | CPU がおすすめの手を教えてくれます（光ったマスをタッチするだけ）。 |
| まった | 何手でも戻せます。負けた後でも「まった」で戻ってやり直せます。 |
| とった駒 | 名前の横に、とった駒と駒得（+3 など）を表示。 |
| 色分け | 自分（しろ）は青、相手（くろ）は赤のうごきマーク・縁取り。 |
| 駒の名前 | 盤が大きい（タブレット・パソコン）ときは駒の名前をカタカナで表示（せっていで切り替え）。 |

「こまの うごき」ボタンでは全部の駒の動きと、とくべつなルール（プロモーション・キャスリング・アンパッサン）を図で見られます。

## チェックメイト問題

画面上の「メイトもんだい」ボタン（またはメニュー）から、50 問の問題集を遊べます。将棋版の詰将棋と同じ遊び方です。

- 自分（しろ）は毎回チェックをかけて、決められた回数でくろのキングをチェックメイトします。駒を選ぶと**チェックになるマスだけ**が光るので、駒の動きを知らなくても挑戦できます。
- くろは一番長く逃げる手を指してきます。
- 回数内にメイトできない手を指すと、キングが逃げて「ざんねん」。「まった」で戻ってやり直せます。
- 「ヒント」で次の正解の手が光ります。「こたえを みる」で解説を読んだり、正解手順を盤に並べたりできます。
- 解けると解説（どう動かしたか・キングの逃げ道をどの駒がふさいでいるか・まちがえやすい手とその逃げ方）を表示。クリアした問題には ★ が付き、記録は自動保存されます。

### 問題の作り方と検証

問題は `tools/gen-mate.js` でランダムな局面から候補を作り（`tools/candidates/` に保存）、メイト問題ソルバー（`js/mate.js`）で次の条件を満たすものだけを残しました。その中から手筋（バックランクメイト・スマザードメイト・すてごま・昇格・ダブルチェック・あきチェックなど）が偏らないように 50 問を選んでいます。解説・タイトル・まちがえやすい手は `tools/explain.js` が局面を調べて作ります。

- ちょうど N 回でメイトでき、それより短くはできない
- 本手順のしろの手がどれも唯一（チェックの中で別の正解がない）
- しろの駒（キング以外）に無駄がない（どれか 1 枚を取り除くとメイトできない）
- ふつうの対局でありうる駒の数（クイーン 1 枚まで など）

`node test/mate.test.js` で、全問の手数・正解手順・唯一性・解説の内容と、「まちがえやすい手」で本当にメイトできないこと（くろの逃げ方まで）を確認しています。

```sh
node tools/gen-mate.js 3 20 42 > candidates.json   # 2かいでメイト（3手）の候補を 20 個（seed 42）
node tools/build-mate-data.js tools/candidates > js/mate-data.js   # 選んだ問題から問題集を作る
```

## ルール

一般的なチェスのルールです。

- 相手のキングをチェックメイトしたら勝ち。
- キャスリング・アンパッサン・プロモーション（昇格）に対応。
- 自分のキングが取られる手は指せないようになっている。
- ひきわけ：ステイルメイト、同一局面 3 回、駒不足（キングだけ／キングとビショップかナイト 1 枚 など）、50 手ルール、400 手。
- ハンデは、CPU 対戦では CPU 側、ふたりで対戦ではくろの駒を減らします（取り除いたルークの側のキャスリングはできません）。

## 遊びかた

1. 動かしたい自分の駒をタッチ。
2. 緑の●のマスをタッチすると動く。赤い○は相手の駒を取れるマス。
3. 迷ったら「ヒント」、間違えたら「まった」。

## Cloudflare で無料公開する

Cloudflare Workers の静的アセット配信を使います。ビルドは不要で、静的ファイルへのリクエストは無料プランでも無料・無制限です。設定はリポジトリに入っている `wrangler.jsonc` / `.assetsignore` / `_headers` だけです。

### 方法 A：GitHub と連携して自動デプロイ（おすすめ）

1. ゲーム本体と `wrangler.jsonc` が入ったブランチを、Cloudflare がビルドする本番ブランチにしておく（このリポジトリの既定ブランチは `master`。ここにマージするか、Cloudflare 側の本番ブランチを変更する）。
2. [Cloudflare ダッシュボード](https://dash.cloudflare.com/) にログイン（無料アカウントで OK）→ **Workers & Pages** → **作成（Create）** → **リポジトリをインポート（Import a repository）**。
3. GitHub を連携して `YYchess` を選ぶ。
4. 設定はそのままで構いません。
   - ビルドコマンド：空欄
   - デプロイコマンド：`npx wrangler deploy`（既定値）
   - ルートディレクトリ：`/`
5. **デプロイ** を押すと `https://yychess.<あなたのサブドメイン>.workers.dev` で公開されます。

以降は本番ブランチに push するたびに自動で再デプロイされます。

### 方法 B：手元のパソコンからコマンドで公開

```sh
npx wrangler login    # 初回のみ。ブラウザで Cloudflare にログイン
npx wrangler deploy   # 公開（URL が表示される）
```

公開前に手元で確認したいときは `npx wrangler dev` で http://localhost:8787 に立ち上がります。

### 公開に関係するファイル

| ファイル | 役割 |
| --- | --- |
| `wrangler.jsonc` | Worker 名（`yychess`）と、リポジトリのルートを静的サイトとして配信する設定。 |
| `.assetsignore` | 公開しないファイル（README・テスト・ツールなど）。 |
| `_headers` | キャッシュとセキュリティ関連の HTTP ヘッダー。 |

## ファイル構成

```
index.html             画面
css/style.css          見た目（スマホ縦向きを基本に、広い画面では2段組み）
js/rules.js            ルールエンジン（指し手生成・合法手・チェックメイト・ひきわけ・SAN・FEN・ハンデ）
js/ai.js               CPU 思考（駒の価値 + 駒の位置の評価 + αβ探索 + 静止探索。制限時間で打ち切り）
js/worker.js           CPU の思考を Web Worker で動かす（画面が固まらない）
js/mate.js             チェックメイト問題ソルバー（正解判定・くろの応手・ヒント）
js/mate-data.js        チェックメイト問題 50 問と解説
js/ui.js               描画と操作（おたすけ表示・ヒント・まった・保存）
manifest.webmanifest   ホーム画面に追加したときの設定
icons/                 アイコン
test/                  Node.js で動くテスト（公開はされない）
tools/                 問題の生成・解説づくりのツール（公開はされない）
```

将棋版と同じく、ルールエンジンは DOM に依存しない純粋な関数で、`apply` は常に新しい局面を返します。AI の探索でも同じ指し手生成（`genMoves` / `make` / `unmake`）をそのまま使っています。`index.html` をファイルとして直接開いた場合など Web Worker が使えない環境では、CPU は画面側で考えます。

```js
require('./js/rules.js'); require('./js/ai.js');
let s = Engine.newGame();
const m = AI.think(s.board, s.turn, s.castle, s.ep, 'normal', s.keys);
s = Engine.apply(s, m);
console.log(s.kifu); // [ 'Nf3' ] など
```

### テスト

```sh
node test/rules.test.js                 # 指し手生成（perft）とキャスリング・アンパッサン・昇格・ひきわけ・SAN
node test/mate.test.js                  # チェックメイト問題 50 問の検証
node test/selfplay.js hard normal 4     # CPU 同士の対戦（強さの確認）
```

指し手生成は、初期局面（20 / 400 / 8902 / 197281）と、よく知られたテスト局面 4 つ（キャスリング・アンパッサン・昇格・ピンを含む "Kiwipete" など）の perft が既知の値と一致することを確認しています。
